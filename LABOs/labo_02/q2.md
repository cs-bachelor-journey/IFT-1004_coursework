## 3.2 Calcul d’année bissextile

---

regle:

- 1. Si l’année est divisible par 4, passez à l’étape 2. Sinon, passez à l’étape 5.
- 2. Si l’année est divisible par 100, passez à l’étape 3. Sinon, passez à l’étape 4.
- 3. Si l’année est divisible par 400, passez à l’étape 4. Sinon, passez à l’étape 5.
- 4. L’année est une année bissextile (elle a 366 jours).
- 5. L’année n’est pas une année bissextile (elle a 365 jours).

**Pseudo-Code:**

### Short method

```text
annee <- demander("Entrez une annee: ")

si annee % 4 == 0 alors:
    #ETAPE 2
    si annee % 100 == 0 alors:
        #ETAPE3
        si annnee % 400 == 0 alors:
            #ETAPE4
            afficher("C'est une année bissextile.")
        sinon:
            #ETAPE 5
            afficher("Ce n'est pas une année bissextile.")
        fin si
    sinon:
        #ETAPE4
        afficher("C'est une année bissextile.")
    fin si
sinon:

    #ETAPE 5
    afficher("Ce n'est pas une année bissextile.")
fin si
```

### ANOTHER METHOD

```text
si (annee % 4 == 0 ET annee % 100 == 0 ET annnee % 400 == 0) OU (annee % 4 == 0 ET annee % 100 != 0) alors:
    afficher("C'est une année bissextile.")
sinon:
    afficher("Ce n'est pas une année bissextile.")
fin si
```

> ANOTHER SOLUTION for the condition

```text
si (annnee % 400 == 0) OU (annee % 4 == 0 ET annee % 100 != 0)
```

## 3.3 Validation de nombre premier

---

```text
nombre <- demander("Entrez un nombre: ")
est_premier <- Vrai

si nombre == 0 ou nombre == 1 alors:
    est_premier <- Faux
sinon:
    # TANT QUE AVEC RACINE CARRE
    i <- 2
    tant que i*i <= nombre faire:
        si nombre % 1 == 0 alors:
            est_premier <- Faux
        fin si
    fin tant que

    # POUR TOUT, INEFFICACE
    pour tout i dans <2, ---, nombre - 1> faire:
        si nombre % 1 == 0 alors:
            est_premier <- Faux
        fin si
    fin pour tout
fin si

si est_premier alors:
    afficher(nombre, "est un nombre premier")
sinon:
    afficher(nombre, "n'est pas un nombre premier")
fin si
```
